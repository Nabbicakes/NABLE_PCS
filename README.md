Pet Clinic System

A Java console application using SQLite and BCrypt for user registration, login, and role-based authentication.

How to Run
1. Clone or download the repository.
2. Open the project in IntelliJ IDEA.
3. Let Maven download the dependencies.
4. Run `Main.java`.
