Pet Clinic System

A Java console-based application using Java, SQLite, Maven, and BCrypt for pet clinic operations and role-based account management.

Features

- Admin: Create Staff accounts, approve registrations, manage users, and view activity logs.
- Staff: Register pets, schedule appointments, manage medical records, record payments, and update appointment and payment statuses.
- Pet Owner: View personal pet records and appointments.
- Security: BCrypt password hashing and role-based authentication.
- Appointment Scheduling: Veterinarian availability checking and double-booking prevention.
- Activity Logs: Records logins, logouts, account updates, appointment activities, and other important actions.

How to Run

1. Clone or download the repository.
2. Open the project in IntelliJ IDEA.
3. Allow Maven to download dependencies.
4. Run `Main.java`.

Default Admin Account

- Username: `admin`
- Password: `12345`

Admin accounts can create Staff accounts and approve pending registrations.

Technologies Used

Java | SQLite | Maven | JDBC | BCrypt
